## Security Model: Zero-Trust Connection String Handling

```
┌─────────────────────────────────────────────────────────────────┐
│  Step 1: User provides Key Vault Secret Name (NOT conn string)  │
│  Input: { "secretName": "ServiceBusConnectionString" }          │
└─────────────────────────────────────────────────────────────────┘
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│  Step 2: Backend creates ephemeral SessionId                    │
│  SessionId: "abc123..."  ExpiresAt: +10 minutes                 │
│  Returns: { "sessionId": "abc123...", "expiresAtUtc": "..." }   │
└─────────────────────────────────────────────────────────────────┘
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│  Step 3: All subsequent API calls use SessionId                 │
│  Backend maps SessionId → SecretName → Connection String        │
│  Connection string NEVER sent to client                         │
└─────────────────────────────────────────────────────────────────┘
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│  Step 4: Receive mode uses ephemeral tokens                     │
│  Backend receives message → generates ephemeralToken            │
│  Stores: ephemeralToken → lockToken (server-side only)          │
│  Client receives ephemeralToken (NOT lockToken)                 │
└─────────────────────────────────────────────────────────────────┘
                             ▼
┌─────────────────────────────────────────────────────────────────┐
│  Step 5: Client confirms receive with ephemeralToken            │
│  Backend maps ephemeralToken → lockToken                        │
│  Calls ServiceBus.CompleteMessageAsync(lockToken)               │
│  Logs audit entry                                               │
└─────────────────────────────────────────────────────────────────┘
```

## Data Flow: Peek Mode

```
User clicks "Peek Mode"
    │
    ▼
Frontend calls /api/stream/{sessionId}/{entityName}?mode=peek
    │
    ▼
Backend validates session and retrieves connection string from Key Vault
    │
    ▼
ServiceBusStreamer creates receiver with PeekLock mode
    │
    ▼
Loop: PeekMessagesAsync() every 2 seconds
    │
    ├─► Messages found?
    │   ├─► YES: Send SSE events with message data
    │   │        event: message
    │   │        data: { messageId, body, properties, ... }
    │   │
    │   └─► NO:  Send heartbeat
    │            event: heartbeat
    │            data: { timestamp: ... }
    │
    ▼
Client receives SSE events via useSSE hook
    │
    ▼
Messages displayed in table (sortable, filterable)
```

## Data Flow: Receive Mode with Confirmation

```
User clicks "Receive Mode"
    │
    ▼
Frontend calls /api/stream/{sessionId}/{entityName}?mode=receive
    │
    ▼
Backend receives messages with ReceiveMessagesAsync()
    │
    ▼
For each message:
    ├─► Generate ephemeralToken (GUID)
    ├─► Store mapping: ephemeralToken → { lockToken, messageId, sequenceNumber }
    └─► Send SSE event with ephemeralToken (NOT lockToken)
        event: message
        data: { token: "ephemeral123...", messageId, body, lockedUntilUtc, ... }
    │
    ▼
Client displays messages with checkboxes
    │
    ▼
User selects messages and clicks "Receive Selected"
    │
    ▼
Confirmation modal shown
    │
    ▼
User confirms
    │
    ▼
Frontend calls POST /api/queue/{sessionId}/{entityName}/receive
    Body: { "tokens": ["ephemeral123...", "ephemeral456..."] }
    │
    ▼
Backend:
    ├─► For each ephemeralToken:
    │   ├─► Lookup lockToken from session mapping
    │   ├─► Call receiver.CompleteMessageAsync(lockToken)
    │   ├─► Log audit entry: { sessionId, entityName, operation: "Receive", messageId, ... }
    │   └─► Remove token mapping
    │
    └─► Return: { completed: [...], failed: [...] }
    │
    ▼
Frontend removes completed messages from UI
```

## Session Lifecycle

```
┌──────────────────────────────────────────────────────────────┐
│  SESSION CREATED                                             │
│  • SessionId: unique GUID                                    │
│  • CreatedAt: timestamp                                      │
│  • ExpiresAt: now + 10 minutes                               │
│  • SecretName: stored (for Key Vault lookup)                 │
│  • TokenMappings: empty ConcurrentDictionary                 │
└──────────────────────────────────────────────────────────────┘
                         │
                         ▼
┌──────────────────────────────────────────────────────────────┐
│  SESSION ACTIVE                                              │
│  • User browses entities                                     │
│  • User streams messages                                     │
│  • TokenMappings accumulate (receive mode)                   │
└──────────────────────────────────────────────────────────────┘
                         │
                         ▼
┌──────────────────────────────────────────────────────────────┐
│  SESSION EXPIRY (after 10 minutes)                           │
│  • Background task removes expired sessions                  │
│  • All token mappings cleared                                │
│  • Future API calls with sessionId → 401 Unauthorized        │
└──────────────────────────────────────────────────────────────┘
                         │
                         ▼
┌──────────────────────────────────────────────────────────────┐
│  USER RECONNECTS                                             │
│  • Must provide secretName again                             │
│  • New sessionId created                                     │
└──────────────────────────────────────────────────────────────┘
```

## Observability & Tracing

```
┌─────────────────────────────────────────────────────────────┐
│  Frontend                                                    │
│  • Generates correlation-id for each request                 │
│  • Header: X-Correlation-ID: web-timestamp-random            │
└─────────────────────────────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────────┐
│  Backend (OpenTelemetry)                                     │
│  • Captures correlation-id from header                       │
│  • Traces API requests, Key Vault calls, Service Bus ops    │
│  • Exports to Azure Monitor / Application Insights           │
└─────────────────────────────────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────────┐
│  Azure Monitor / Application Insights                        │
│  • End-to-end distributed tracing                            │
│  • Query by correlation-id to see full request flow         │
│  • Metrics: latency, error rates, throughput                 │
└─────────────────────────────────────────────────────────────┘

Example Kusto Query:
    traces
    | where customDimensions.CorrelationId == "web-1731585600-abc123"
    | order by timestamp asc
    | project timestamp, message, severityLevel
```
